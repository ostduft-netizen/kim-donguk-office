# 김동욱 비서실

김동욱 님 전용 모바일 비서실 앱(PWA)입니다. 따뜻한 우드 톤의 교수님 서재 오피스 콘셉트로,
15개 책상(업무 파트)과 5개 브랜드·채널 보드를 한 화면에서 봅니다.

▶ **설치형 앱**: https://ostduft-netizen.github.io/kim-donguk-office/
안드로이드 크롬은 주소창 옆 설치 아이콘 또는 앱 안의 ‘설치’ 배너, 아이폰 사파리는
공유 → ‘홈 화면에 추가’로 설치하면 주소창 없는 앱으로 열립니다. 한 번 열면 오프라인에서도 동작합니다.

## 구성
- `index.html` — 앱 본체 (모바일 우선, 최대 430px)
- `office-map.png` · `avatar.png` — 오피스 맵(5열×3행 15책상)과 프로필 캐릭터
- `manifest.webmanifest` · `sw.js` · `icon-192.png` · `icon-512.png` — PWA 설치·오프라인 캐시
- `README.md`

## 15개 책상 워크플로
책상마다 **최종 산출물 + 4~5단계 파이프라인 + 체크리스트 + 작업 메모**가 있습니다.
체크 상태와 메모는 브라우저 `localStorage`에 저장되고, 진행률은 오피스 맵 아바타 링(금색 호)과
비서현황(책상별 %, 전체 %)에 실시간 반영됩니다.

| 책상 | 최종 산출물 |
|---|---|
| 정부지원 | 지원사업 신청서 제출본 (지원사업 비서) |
| 산학협력 | 납품 검수 완료 + 정산 서류 |
| 10:30 브리핑 완료 | 브리핑 카드 + 다음 브리핑 예약 |
| B2B | 제안서 발송 + 견적 확정본 |
| 글로벌 | 캠프 운영 완료 + 결과 보고서 |
| 회계·세무 | 세금계산서 발행 + 증빙 백업 |
| 논문·IRB | SSCI/KCI 투고 완료 원고 1편 |
| 홍보·링크드인 | 주간 링크드인 글 1편 |
| 강의·부산대 | 기말 페이퍼 마감 + 성적 입력 |
| 취재·기고 | 게재 완료 + 링크 아카이브 |
| 서류·행정 | 서류 묶음 제출 + 접수증 |
| 브런치 | 글 발행 + 브런치북 목차 |
| 영상·미디어 | 클립 1편 공개 + 아카이브 |
| 개발·자동화 | 자동화 1건 가동 + 문서화 |
| 유누스코리아 | 캠프 준비 완료 + 이사회 보고 |

### 논문 파이프라인 (SSCI / KCI)
① 주제 발굴·갭 분석 → ② 문헌조사·선행연구 매트릭스 → ③ 연구설계·데이터/IRB →
④ 초안 작성·영문 교정 → ⑤ 저널 투고·리뷰어 대응, 그리고 **최종 투고 패키지 6종**
(본문·초록·레퍼런스 양식·IRB 승인서·Cover Letter·Response Matrix).
트랙별로 **SSCI 영문 / KCI 국문** 목표를 토글해 저장합니다. 작업실 상단에 두 트랙 진행률이 모입니다.

### 지원사업 비서
정부지원 책상을 열면 **공고 보드 · 기관 매칭 · 준비 가이드**가 나옵니다.
가이스트(창업·B2B·R&D·바우처), 유누스코리아(비영리·SDGs·공익), 린스크(출판·콘텐츠·유통) 3트랙으로
공고를 필터링하고, 공고를 열면 **자격 체크 → 필수 서류 → 사업계획서 5목차 → 협약·정산** 18개 항목을
한 화면에서 진행합니다. D-day와 적합도는 자동 계산됩니다.

## 공개 범위
이 저장소는 공개되어 있습니다. 그래서 화면의 일정·금액·거래처 세부는 일반화해 표시했고,
개인 생일·납품 금액·사무실 주소·상대방 실명은 넣지 않았습니다. 3건은 ‘예시 공고’로 표시했습니다.

가계부·메모·워크플로 체크는 브라우저 `localStorage`에만 저장되며 서버로 전송되지 않습니다.
