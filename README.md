# 김동욱 비서실

김동욱 님 전용 모바일 비서실 대시보드입니다. 따뜻한 우드 톤의 교수님 서재 오피스 콘셉트로,
15개 책상(업무 파트)과 5개 브랜드·채널 보드를 한 화면에서 봅니다.

## 구성
- `index.html` — GitHub Pages용 앱 (이미지는 `office-map.png`, `avatar.png` 상대경로)
- `office-map.png` — 5열 × 3행, 15개 책상 오피스 맵
- `avatar.png` — 프로필 캐릭터

## 메뉴
오피스 맵 · 월별 스케줄 · 채널보드 · 회의실 · 작업실 · 비서현황 · 자동루틴 · 가계부 · 메모

가계부와 메모는 브라우저 `localStorage`에만 저장되며 서버로 전송되지 않습니다.

## 공개 범위
이 저장소는 공개되어 있습니다. 그래서 화면의 일정·금액·거래처 세부는 일반화해 표시했고,
개인 생일·납품 금액·사무실 주소·상대방 실명은 넣지 않았습니다.

자립형 단일 파일 버전(이미지 base64 내장)은 로컬 `office/김동욱-비서실.html`로 따로 보관합니다.
